# J&L Suportes

## Status do projeto
Concluído para fins acadêmicos - UC15.

## Sobre o projeto
O **J&L Suportes** é um sistema desktop desenvolvido para auxiliar no gerenciamento de atendimentos de suporte técnico. O projeto foi desenvolvido como atividade da UC15 do curso de Análise e Desenvolvimento de Sistemas do SENAC.

## Objetivo
Centralizar o cadastro de clientes, usuários e chamados técnicos, permitindo registrar e consultar informações de atendimento com persistência em banco de dados MySQL.

## Funcionalidades
- Login de acesso ao sistema
- Dashboard com informações do banco de dados
- Cadastro e consulta de clientes
- Cadastro e consulta de usuários
- Abertura de novos chamados
- Consulta de chamados
- Controle de status e prioridade dos chamados
- Associação de chamados a clientes e técnicos
- Persistência dos dados em banco MySQL

## Tecnologias utilizadas
- Java
- Java Swing
- JDBC
- MySQL
- MySQL Connector/J
- Apache NetBeans
- Git e GitHub

## Banco de dados
O projeto utiliza o banco de dados **jl_suportes**. O script SQL necessário para criação da estrutura acompanha o projeto na pasta `database`.

A configuração de acesso ao MySQL deve ser ajustada conforme o ambiente em que o sistema for executado.
